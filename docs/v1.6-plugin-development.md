# v1.6 插件开发

> 供 Codex 实现。基于 v1.5 通用框架，开发第一个标准插件：会话持久化。

日期：2026-11-11。前置：v1.5（c77f377）。理由见 decisions-v1.4.md D2。

---

## 背景

v1.5 已完成框架通用化（entry point 发现、Hook 完整化、api/ 边界清理）。现在框架支持任意插件，但尚无实际插件实现。

v1.6 的目标：开发**会话持久化插件**，作为标准 Capability 插件的参考实现。验证框架的通用性，同时解决实际需求（重启后恢复会话）。

#### 1.2 Capability 实现

`capability.py`：

```python
from core.kernel.capability import Capability
from core.kernel.hook import Hook
from .hook import SessionPersistenceHook
from .config import SessionPersistenceConfig
from .backends import create_backend

class SessionPersistenceCapability(Capability):
    """会话持久化能力：使用 Hook 生命周期实现会话存储。"""
    
    def __init__(self, config: SessionPersistenceConfig | None = None):
        self.config = config or SessionPersistenceConfig()
        self.backend = create_backend(self.config)
        self._hook = SessionPersistenceHook(self.backend)
    
    @property
    def name(self) -> str:
        return "session_persistence"
    
    def tools(self) -> list[BaseTool]:
        return []  # 不提供工具（用户无需手动调用）
    
    def hooks(self) -> list[Hook]:
        return [self._hook]
    
    async def initialize(self, config: dict) -> None:
        """v1.5 生命周期：能力启动时调用"""
        await self.backend.initialize()
    
    async def close(self) -> None:
        """v1.5 生命周期：能力关闭时调用"""
        await self.backend.close()
```

#### 1.3 Hook 实现

`hook.py`：

```python
from core.kernel.hook import Hook
from core.kernel.state import AgentState
from langchain_core.messages import ToolMessage, BaseMessage
from .backends.base import Backend

class SessionPersistenceHook(Hook):
    """会话持久化 Hook：使用 v1.5 完整生命周期。"""
    
    def __init__(self, backend: Backend):
        self.backend = backend
    
    async def on_start(self, config: dict) -> None:
        """引擎启动时：确认 backend 已准备好"""
        # Backend 在 Capability.initialize 中已初始化
        pass
    
    async def on_session_load(self, session_id: str) -> AgentState | None:
        """轮开始前：会话恢复（v1.5 新增钩子）"""
        data = await self.backend.load(session_id)
        if data is None:
            return None
        
        # 反序列化消息
        messages = self._deserialize_messages(data["messages"])
        
        # 检查悬空调用，补"未执行"结果
        messages = self._fill_dangling_calls(messages)
        
        # 恢复 context（v1.5 会校验身份）
        context = data.get("context", {})
        
        return AgentState(messages=messages, context=context)
    
    async def after(self, state: AgentState) -> AgentState:
        """每轮结束：写盘"""
        # 从 context 获取 session_id（v1.5 机制）
        from core.kernel.context import get_thread_id
        session_id = get_thread_id()
        
        if session_id:
            await self.backend.save(
                session_id=session_id,
                data={
                    "messages": self._serialize_messages(state["messages"]),
                    "context": state.get("context", {})
                }
            )
        
        return state
    
    async def on_session_close(self, session_id: str) -> None:
        """会话关闭时：删除存储（v1.5 新增钩子）"""
        await self.backend.delete(session_id)
    
    async def on_stop(self) -> None:
        """引擎停止时：确保 backend 已清理（v1.5 新增钩子）"""
        # Backend 在 Capability.close 中已清理
        pass
    
    def _serialize_messages(self, messages: list[BaseMessage]) -> list[dict]:
        """使用 LangChain 内置序列化"""
        from langchain_core.messages import messages_to_dict
        return messages_to_dict(messages)
    
    def _deserialize_messages(self, data: list[dict]) -> list[BaseMessage]:
        """使用 LangChain 内置反序列化"""
        from langchain_core.messages import messages_from_dict
        return messages_from_dict(data)
    
    def _fill_dangling_calls(self, messages: list[BaseMessage]) -> list[BaseMessage]:
        """工具调用没有对应结果时，补一条 ToolMessage。"""
        result = []
        pending_calls = {}
        
        for msg in messages:
            result.append(msg)
            if hasattr(msg, 'tool_calls') and msg.tool_calls:
                for tc in msg.tool_calls:
                    pending_calls[tc["id"]] = tc
            elif isinstance(msg, ToolMessage):
                pending_calls.pop(msg.tool_call_id, None)
        
        # 剩下的是悬空的
        for call_id, tc in pending_calls.items():
            result.append(ToolMessage(
                content="因服务重启，此工具调用未执行",
                tool_call_id=call_id,
                name=tc["name"]
            ))
        
        return result
```

#### 1.4 Backend 接口

`backends/base.py`：

```python
from typing import Protocol

class Backend(Protocol):
    """存储后端协议：所有方法必须幂等。"""
    
    async def initialize(self) -> None:
        """初始化：建立连接、创建表等。"""
    
    async def save(self, session_id: str, data: dict) -> None:
        """保存会话。幂等：同个 session_id 重复 save 不出错。"""
    
    async def load(self, session_id: str) -> dict | None:
        """加载会话。返回 None 表示不存在或已过期。"""
    
    async def delete(self, session_id: str) -> None:
        """删除会话。幂等：删除不存在的不出错。"""
    
    async def list_expired(self, retention_days: int) -> list[str]:
        """列出过期的 session_id（用于清理）。"""
    
    async def close(self) -> None:
        """清理资源：关闭连接池等。"""
```

#### 1.5 三种 Backend 实现

**MemoryBackend**（默认，零依赖）：
- 字典存储，进程内
- 重启丢失（验证 Hook 机制的最小实现）

**SqliteBackend**（单机持久化）：
- 依赖：`aiosqlite`
- 表：`sessions(session_id PRIMARY KEY, data_json TEXT, updated_at TIMESTAMP)`
- 文件路径：`~/.aro/sessions.db`（可配置）

**PostgresBackend**（企业级）：
- 依赖：`asyncpg`
- 表结构同上，连接池化
- 连接串从环境变量读取：`ARO_DB_URL`

#### 1.6 配置

`config.py`：

```python
from pydantic import BaseModel, Field

class SessionPersistenceConfig(BaseModel):
    """会话持久化配置"""
    backend: str = Field(default="memory", description="memory / sqlite / postgres")
    sqlite_path: str | None = Field(default=None, description="SQLite 文件路径")
    retention_days: int = Field(default=30, description="存储保留天数")
```

在 `projects/helpdesk/config/agent.yml` 中启用：

```yaml
capabilities:
  session_persistence:
    backend: sqlite
    sqlite_path: ~/.aro/sessions.db
    retention_days: 30
```

### 任务 2：现有能力标准化（可选，时间允许的话）

将现有四个 Hook（Trace、HITL、Memory、Delegation）包装成标准 Capability，支持 entry point 注册。

**不改逻辑**，只是增加 Capability 包装器，让它们可以被外部包引用和替换。

示例（Trace）：

```python
# capabilities/trace/capability.py

class TraceCapability(Capability):
    def __init__(self, config: TraceConfig | None = None):
        self.config = config or TraceConfig()
        self._hook = TraceHook()  # 现有实现不改
    
    @property
    def name(self) -> str:
        return "trace"
    
    def tools(self) -> list[BaseTool]:
        return []
    
    def hooks(self) -> list[Hook]:
        return [self._hook]
```

其他三个（HITL、Memory、Delegation）同理。

## 关键设计点

1. **使用 v1.5 Hook 生命周期**：on_session_load 恢复、after 写盘、on_session_close 删除
2. **session_id 从 context 获取**：使用 v1.5 的 `get_thread_id()` 机制
3. **身份校验由框架保证**：v1.5 已实现，插件无需重复校验
4. **Backend 是可替换的**：三种实现共享同一协议
5. **LangChain 内置序列化**：`messages_to_dict` / `messages_from_dict`
