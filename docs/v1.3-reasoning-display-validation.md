## R1 修正与协议边界

chat / chat_stream 均先执行 `_convert_tools`，再将 `bool(openai_tools)` 传给 `_convert_messages(..., tools_present=...)`。组装 HTTP 请求时复用同一转换结果。

- 输入非空但转换为空（`tools=[object()]`）：请求不发送 tools，也不回传 reasoning_content。
- 仅模型识别为 DeepSeek、enable_thinking=True、实际发送非空 tools 三条件同时成立时，允许独立 reasoning_content 协议字段。
- AIMessage.additional_kwargs 保存该元数据；不拼入消息 content、提示词、Trace.agent_response 或工具参数。
- 三个扩展契约与 Engine 装配未改，不引入依赖。

HTTP 请求级回归使用真实 OpenAI SDK + httpx.MockTransport 捕获请求体；无外网调用、无真实密钥。矩阵覆盖流式/非流式、DeepSeek/非 DeepSeek、思考开/关，以及有效工具、空列表、被忽略对象、None。断言检查实际 tools 字段与 reasoning_content 字段，避免只验证原始入参。

## 展示与事件行为

- 流式 reasoning_delta 单独发出 reasoning；同一块兼有思考和正文时先发思考。非流式整段发出一次。
- 委派转为 agent_reasoning，携带 agent_name 和 parent_call_id；前端独立来源块展示、持久化，专家正文不拼入总控正文。直连专家沿用普通 reasoning。
- 当前回复流式展开，正文开始后折叠；用户手动展开后不被后续正文 token 反复关闭。旧回复不随下一轮 busy 重新展开。
- 无内容不渲染；浏览器本地历史保存并校验块文本、来源和耗时。
- reasoning 同走 encode_event 的既有脱敏；使用现有 CSS 主题 token。
- 耗时为浏览器首个思考事件至正文/结束的观察间隔，可能包含工具等待，非模型纯计算时长；summary 的说明明确这一口径。
