## 范围与实现

运行代码只改 `core/kernel/engine.py`、`core/kernel/loop.py`：

- Engine 的 for 多轮驱动替换为一次 StateGraph 调用，公开 run 签名与既有校验不变。
- 图为 agent/tools/after 加条件边；run_once 走同图的单轮模式。
- 四个钩子、权限、工具串行执行、SSE 事件字段与顺序保留；工具执行分支沿用原实现，不引入 ToolNode。
- 每次运行使用独立的共享执行 Context，跨节点保留 identity、事件 sink 与委派 scope，不让 ContextVar 的写入在节点边界丢失。
- 私有图状态用完整业务状态的 LastValue 通道；不重复合并消息，保留历史删除和消息引用。
- 请求局部 KernelRun 保存最新业务状态，供异常/取消时 Engine Trace.finish 使用；不将运行帧、Context 或 Future 放入图状态。
- HITL A 及能力保持原样；图编译不传 Checkpointer、不使用 interrupt、不配置重试、不实现恢复或重放。

详细图和执行顺序见 [内核运行时说明](design/kernel-runtime.md)。本步明确不执行提案中的 MemorySaver 接入部分，以用户最新放行范围为准。
