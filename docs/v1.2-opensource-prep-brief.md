### 2. `frontend/src/components/SituationPanel.tsx`（整文件，航空形状，与真实后端对不上——这是功能 bug）
真实后端 `projects/helpdesk/workbench.py::panel()` 返回的字段是：


要求：按 `panel()` 真实返回重写面板的类型(`Situation`/`Declaration` → 如 `Panel`/`Ticket`)、类型守卫 `isSituation`、

工单字段参考 `projects/helpdesk/repositories/base.py` 的 `Ticket`（id/title/category/priority/status/requester/assignee/created_at…）。
保留原有交互骨架（刷新、选中、"检测重复"/"生成报告"按钮、产物卡片），只把领域语义从航空换成工单。
`App.tsx` 里对应的 import、`isSituation`、`Situation` 类型引用同步更新。**改完前端须能 `npm run build` 通过**。
