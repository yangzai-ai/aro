## 代码与边界

- `frontend/src/components/Sidebar.tsx`：导航、历史与专家目录。
- `ChatWindow.tsx` / `VoiceButton.tsx`：Markdown 消息、快捷输入、多行编辑、语音、发送与停止。
- `TicketPanel.tsx`：真实面板类型、运行时守卫与渲染；删除旧 SituationPanel。
- `frontend/src/history/storage.ts`：存储读取校验、写入异常降级及 sessionStorage 安全访问。令牌仅在页面内存，不保存到浏览器存储。
- `frontend/src/theme/theme.css`：集中颜色、主色/强调色、字号/字体、间距、圆角、密度与面板样式 token；`theme.ts` 管理两个独立设置；`index.html` 在首屏样式/React 渲染前恢复允许的设置，生产构建 CSS 在 head 中加载。
- `App.tsx` 保留 generation/epoch、AbortController、身份匹配的回填检查；历史切换、令牌变更、新建均清空旧面板/来源/专家/Trace/审批。新建期间禁用输入，不显示没有作用的“停止”按钮。
- `client/api.ts` 的 streamChat、submitApproval、projectRequest 函数主体与基准 `1cab1fe` 逐字一致。仅 checked 的原 Error 改为继承 Error 的 HTTPError，附 status，让前端区分 404 和暂时失败；请求路径、载荷、认证、SSE 解析与取消语义不改。
- 后端仅改 `projects/helpdesk/api.py` 并新增项目专家/配置；core、三个扩展契约、既有通用 API 和能力实现不改。未新增依赖，未新增 LangGraph import。
