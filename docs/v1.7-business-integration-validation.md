### 新增覆盖重点

- Trace：实际 Engine 流式执行后查单条/列表；/api 别名；会话绑定跨会话 404；无头 422；旧 Trace 按最近一轮策略不可见；过期 404；部署 token 401；模型密钥/部署 token/URL 凭据脱敏；分页边界和 OpenAPI schema；在途 current_trace 不对外暴露。
- Client：全部 13 类型、UTF-8 逐字节、CRLF 任意分块、纯 CR、多行 data、注释、未知事件；断流/坏 JSON/网络异常只发送一次 POST；非终止 error 继续、终止 error 无需 done、终止帧后传输失败不把已知结果误判未知；GET 重试上限、401/403/404 不重试、取消退避、审批不重试、host 回调异常保留。
- React：五组件真实渲染、默认文本转义、空思考不渲染、自动/手动折叠、真实工具证据、到期审批禁用；首轮创建/第二轮复用；专家正文与思考不进入总控正文；会话/目标切换忽略旧事件；reset/stop/unmount 清理与取消；并发发送互斥；审批绑定且旧决定不清空下一条审批。

## 包消费复验

## 明确限制

- 无聊天自动重放、续传、createSession、客户端身份覆盖或事件版本协商。聊天断流执行结果未知，需查业务系统/Trace；GET 重试不能被称作聊天重连。
- Trace 是当前活跃会话内存中已结束记录，HTTP 默认最近一轮；不是历史审计、持久化或完整多租户授权。部署共享 token 和会话 ID 不能替代业务代理的用户归属校验。
- 内核、Engine、Hook、Capability、会话持久化、SSE 事件 producer 与 TraceHook 未改。
- 依用户要求单独提交，提交后暂停复验；不推送、不打 tag。
