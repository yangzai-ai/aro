# v1.5 框架通用化批复

日期：2026-11-10。来源：用户在本任务中的明确确认。

同意按 [装配提案](v1.5-framework-generalization-proposal.md) 实施；简报描述目标，提案规定实施细节。

1. discover 支持过滤参数，默认仅加载配置启用项；显式能力列表（包括空列表）优先，加载失败保留回滚。
2. 保留 Hook ABC，增加默认生命周期方法；异步 create 完成前启动，不能在同步构造器运行异步钩子，首次 run 前确保启动。
3. session_id 来自 state.context.thread_id，恢复状态的 thread_id/tenant_id/user_id 必须校验，冲突拒绝。
4. 内核定义审批和专家目录服务类型协议，项目负责具体能力适配；这些是 Hook/宿主的服务边界，不是新的扩展点。不新增 TraceService。
5. core 和 api 均禁止导入具体 capabilities 类；projects 可以导入。
6. 至少 3 项发现、5 项生命周期测试，并补身份冲突、回滚、AST 边界测试；不实现 v1.6 持久化插件。
