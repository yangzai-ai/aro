# v1.6 插件开发批复

日期：2026-11-11。依据：用户在本任务的明确确认；[实施提案](v1.6-plugin-development-proposal.md) 的冲突及口径获批准。

1. 允许限定框架补修：core/kernel/context.py 提供 get_thread_id() 与 bind_thread_id(thread_id)；Engine 调图前绑定，在作用域退出时 reset，不改图执行流程。
2. delete_on_session_close 默认 False，关闭运行不等于永久删除。默认由 retention_days 控制有效期，显式 True 才在关闭时删除，该模式不支持关闭后恢复。
3. Capability.initialize 保持同步配置；Hook.on_start 初始化 backend，on_stop 关闭，Capability.close 幂等兜底。
4. 悬空调用补“因服务中断，此工具调用未记录结果，执行状态未知；未自动重放，请先查询业务系统核实。”结果放对应批次结束处，不在历史末尾，不重放工具。
5. 本轮仅交付受信 thread_id 的 Engine 重建恢复，不宣称浏览器跨重启续聊；API 恢复鉴权/会话装配另行设计。
6. 三 backend 为 Memory/SQLite/PostgreSQL，驱动按需导入并使用可选依赖。不做旧能力额外包装或权限清单。
