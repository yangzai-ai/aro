## 实施范围

- memory：新增 `core/kernel/store.py`，中立 KVStore/KVItem 协议、进程内默认实现及 shared_store 工厂。第三方 Store 构造与 item 转换只在内核；能力没有转发第三方类型。能力调用参数、默认值与关键字限制不变，backend 注解按任务要求从 BaseStore 改为 KVStore。自定义结构化后端可以直接注入，无需继承默认实现。
- multiagent：删除 Supervisor 的 DispatchState 与单节点图，直接 await handle.invoke，保留结果模型校验与 agent_name 一致性校验；没有内核派发层。
- HITL：仅删除未接入的旧 PostgreSQLCheckpointer 文件及其独占测试。Future 审批链、中间件和 ApprovalManager 不变。
- tests 零 import：内核增加 default_checkpointer 工厂，Engine/run_once 复用原默认构造；检查点测试经工厂和内核模块白盒访问完成原验证。工厂实际返回原生 MemorySaver，注入与清理语义未改。
- 更新当前内核运行时说明；历史 Phase 1 验收记录保留当时事实。
