# 工单状态 Word 模板

`ticket.docx` 是服务端受控 docxtpl 模板源码资产，不是生成报告。
正文包含申报/计划、当前状态、观察到的审批、已执行检测和数据来源边界。
占位符仅接收项目 Workbench 从公开 Repository/成功工具证据构造的字符串。
模型不能选本地路径、改模板或传入权威状态。

修改后必须实际生成正常、未检测/无审批记录、长中文/换行/`& < >`/模板样式数据样本，
用 LibreOffice/Word 打开并逐页渲染目检。表格固定标签列和可换行值列，无固定行高；
正常报告一页，较长数据允许自然分页。模板变化的视觉证据见 v1.0 自测报告。
生成目录位于 data 下且被忽略；模板本身应随功能源码纳入后续人工提交。
