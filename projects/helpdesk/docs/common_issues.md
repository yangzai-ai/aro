# IT Support Common Issues

## Email Access

**Q: Cannot log in to email after password reset**
A: Clear browser cache, wait 5 minutes for password sync, try incognito mode.

## Network

**Q: WiFi frequently disconnects**
A: Check signal strength, restart router, update network drivers.

## Printer Issues

**Q: Printer error code E05**
A: Paper jam detected. Open front cover, remove jammed paper, close cover and restart.
